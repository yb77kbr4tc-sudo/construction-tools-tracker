# Construction Tools Tracker

A simple mobile-friendly tools tracking app for a construction company.

## What it does
- Add new tools
- Search inventory
- Check tools out to workers
- Assign tools to sites
- Check tools back in
- View recent activity
- Stores data in the browser using local storage

## Run it locally
Open `index.html` in a browser.

You can also run a quick local web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes
This is the fastest MVP version to get started quickly on phones and tablets without requiring a backend setup.
